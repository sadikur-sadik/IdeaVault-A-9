## Description :
### Welcome to my new project idea vault where people can delve into a different realm of startup ideas. This is a platform to upload your ideas, view others ideas, and communicate with them which might open a door for future partnership.

## Top Features :

- slider Banners which gives an overview about the website
- Features, stats sections to understand the website and its growth better.
- Featured ideas section which comes filtered from backend. 
- Watching people's ideas, seeing the details of the idea and interact with them with comments.
- Adding your own ideas
- Idea history where Idea can be edited or deleted
- My interaction section where one can see his interaction history.
- Authentication with better auth and authorization with JWT and Proxy
